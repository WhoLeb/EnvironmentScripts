# About
These are the environment scripts that i share between most my workstations containing convenient aliases and tiny scripts

These also contain my preferred oh-my-posh style, this can obviously be swapped/disabled.
# How it works
## Powershell
```powershell 
git clone https://github.com/WhoLeb/EnvironmentScripts.git
```
to any directory.
In your $PROFILE (```nvim $profile```) include the files from pwsh, relaunch the terminal and it should work. 

Another option is to just paste the aliases you want directly into $profile.
